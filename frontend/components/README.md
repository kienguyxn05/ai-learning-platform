# Components Directory

This directory contains modular React components organized by feature:

- `course/`: Components for course lists, cards, and outlines.
- `lesson/`: Components for video player, lesson notes, and transcripts.
- `tutor/`: AI Tutor chat interface and messaging components.
- `quiz/`: Quiz question cards, option selectors, and score summaries.
- `ui/`: Shared, generic UI components (buttons, badges, inputs, dialogs).
